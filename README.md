# 📊 Análisis de Riesgo Financiero en Inventario y Mermas (Power BI)

## 🎯 Objetivo del Proyecto
Desarrollar un dashboard interactivo enfocado en la auditoría interna y el control de inventarios, identificando mermas críticas y categorizando el riesgo financiero para optimizar la toma de decisiones.

## 🔍 Hallazgos Principales (Key Insights)
- **Concentración del Riesgo:** El mayor impacto financiero por mermas se concentra en productos con vida útil restante inferior a 30 días.
- **Categoría Crítica:** La categoría Agroquímicos presenta el volumen de pérdida más elevado, destacando productos con alta rotación pero desfase en control operativo.
- **Eficiencia Operativa:** Permite monitorear la relación entre costo unitario, costo de transporte y precio de venta para maximizar márgenes.

---

## 🛠️ Herramientas y Metodología
- **Power BI Desktop:** Modelado de datos y visualización.
- **Power Query:** Limpieza, transformación y estructuración de tablas.
- **DAX:** Creación de medidas dinámicas para semaforización de riesgo e impacto monetario.
